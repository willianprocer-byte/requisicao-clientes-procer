═══════════════════════════════════════
FERRAMENTA: atualizar_amostragem
═══════════════════════════════════════

tipo = "atualizar_amostragem" (FIXO)

Cada item em dados.silos precisa:
- identificador OU numero (ex: "SILO 3" ou "3")
- amostragem.umd OU amostragem.imp OU amostragem.avr (pelo menos um)
- produto (opcional, ex: "SOJA")

JSON que FUNCIONA (testado):
{
  "tipo": "atualizar_amostragem",
  "cliente_nome": "Willian Medeiros Tramontin - Procer Teste - SC",
  "descricao": "SILO 3 soja UMD 11.5 IMP 0.3 AVR 5.7",
  "dados": {
    "silos": [
      {
        "identificador": "SILO 3",
        "numero": "3",
        "produto": "SOJA",
        "amostragem": {
          "umd": 11.5,
          "imp": 0.3,
          "avr": 5.7
        }
      }
    ]
  }
}

Erros comuns:
❌ Falta cliente_nome
❌ Falta dados.silos (array)
❌ Falta identificador ou numero no silo
❌ amostragem sem umd/imp/avr
❌ umd/imp/avr como string "11.5" em vez de número 11.5

═══════════════════════════════════════
DICA PARA CONFIGURAR NO CONVERT
═══════════════════════════════════════

Se a ferramenta pede campos separados, mapear assim:

cliente_nome  → $name (nome exato do contato)
descricao     → resumo montado pela IA
dados         → objeto JSON montado pela IA com silos[]

O campo "tipo" pode ser FIXO em cada ferramenta (não precisa a IA enviar se já está na URL/body template).

O campo $id_silo está chegando LITERAL ("$id_silo") em vez do número do silo.
No Convert, mapear id_silo para o valor real (ex: "3"), não a variável.

Campos que devem ser preenchidos SEPARADOS na ferramenta:

atualizar_nivel_silo:
- numero: "3" (número do silo)
- identificador: "Silo 3" (nome legível)
- nivel: "cheio" | "vazio" | "finalizando" | "parcial"
- tipo_silo: "pulmao" (opcional)

atualizar_amostragem:
- numero: "3"
- identificador: "Silo 3"
- produto: "SOJA"
- umd, imp, avr (números)

atualizar_produto:
- numero: "12"
- identificador: "Silo 12"
- produto: "SOJA" ou "MILHO"

NÃO enviar só identificador: "1" — enviar numero + identificador formatado.
NÃO deixar variáveis $id_silo sem substituir.

Me manda o erro exato do log (detalhes[]) que te ajudo a identificar qual campo faltou!
